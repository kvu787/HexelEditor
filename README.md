# Hexel Editor

Two applications share this repository, and one `Conversations` folder at the root records the conversations behind both.

| Folder                    | What it holds                                                                                     |
| ------------------------- | ------------------------------------------------------------------------------------------------- |
| `HexelEditor_Wpf`         | The hexagonal-grid art editor, built with C#, .NET 10, WPF and SkiaSharp. See its README.         |
| `GodotAgentDevExperiment` | An experiment in developing, testing and measuring a Godot 4.7.2 C# application non-disruptively. |
